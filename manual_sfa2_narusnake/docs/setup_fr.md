# Guide d'installation du Manual Street Fighter Alpha 2

## Logiciels requis

- Archipelago avec le client Manual.
- Le fichier `manual_sfa2_narusnake.apworld` installé dans le dossier `custom_worlds` d'Archipelago.
- Street Fighter Alpha 2, disponible via Street Fighter Alpha Anthology sur PlayStation 2.

## Installation

1. Copiez `manual_sfa2_narusnake.apworld` dans le dossier `custom_worlds` d'Archipelago.
2. Redémarrez Archipelago pour que le monde soit chargé.
3. Générez ou modifiez un YAML pour `Manual_SFA2_NaruSnake`.
4. Générez le multiworld comme d'habitude.

## Rejoindre une partie multiworld

1. Ouvrez le client Manual depuis le launcher Archipelago.
2. Connectez-vous au serveur multiworld avec l'adresse de la room, le nom du slot et le mot de passe si nécessaire.
3. Gardez le client Manual ouvert pendant que vous jouez.

## Fonctionnement du Manual

Ceci est un monde Manual. Le jeu lui-même n'est pas patché, donc vous devez suivre le tracker et utiliser seulement les personnages, modes, niveaux de Super Combo et options de jeu optionnelles après avoir reçu l'item correspondant.

Validez une location dans le client Manual lorsque vous terminez la tâche correspondante en jeu.

## Dépannage

Si le générateur de YAML n'affiche pas `Manual_SFA2_NaruSnake`, vérifiez que le fichier `.apworld` est bien installé dans `custom_worlds`, puis redémarrez Archipelago.

Si des options optionnelles sont désactivées dans le YAML, les items et checks correspondants doivent être retirés de la génération.
