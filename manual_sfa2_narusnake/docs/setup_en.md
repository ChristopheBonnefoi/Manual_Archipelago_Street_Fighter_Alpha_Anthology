# Street Fighter Alpha 2 Manual Setup Guide

## Required Software

- Archipelago with the Manual client.
- The `manual_sfa2_narusnake.apworld` file installed in your Archipelago `custom_worlds` folder.
- Street Fighter Alpha 2, available through Street Fighter Alpha Anthology on PlayStation 2.

## Installation Procedures

1. Copy `manual_sfa2_narusnake.apworld` into Archipelago's `custom_worlds` folder.
2. Restart Archipelago so the world is loaded.
3. Generate or edit a YAML for `Manual_SFA2_NaruSnake`.
4. Generate the multiworld as usual.

## Joining a MultiWorld Game

1. Open the Manual client from the Archipelago launcher.
2. Connect to the multiworld server with your room address, slot name, and password if one is required.
3. Keep the Manual client open while playing.

## Multiplayer Manual

This is a Manual world. The game itself is not patched, so you must follow the tracker and only use characters, modes, super combo levels, and optional game settings after receiving the matching item.

Mark a location checked in the Manual client when you complete the matching in-game task.

## Game Troubleshooting

If the YAML generator does not list `Manual_SFA2_NaruSnake`, make sure the `.apworld` is installed in `custom_worlds` and restart Archipelago.

If optional settings are disabled in the YAML, the matching option items and option checks should both be removed from generation.
